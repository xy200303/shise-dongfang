# Miora 设计任务包

> 使用方法：把下面每个任务的 prompt 逐条粘贴到 Miora，产出物保存到 `docs/task02/miora/`（截图/源文件），并在《全流程记录.md》登记。
> 所有产出共用同一套「设计基调」，每条 prompt 都带上【基调】段落，保证视觉风格不跑偏。

## 设计基调（每条 prompt 必带）

```
【基调】东方美学 / 宋式极简 / 大量留白 / 宣纸质感。亮色模式：米白宣纸底 #FAF8F4、
墨色文字 #1A1A18、1px 细分隔线 #E8E5DF；深色模式：玄色底 #141310、米白文字。
标题用衬线宋体（思源宋体），正文现代黑体，数据用等宽字体。圆角 8px，阴影极克制。
点缀色即当前主题传统色（默认朱砂 #C8473F）。禁止：渐变堆砌、毛玻璃滥用、3D 元素、emoji。
```

## 任务清单

### M1 · 品牌 Logo

```
【基调】（见上）
设计「拾色 · 东方」品牌 Logo：文字标为主，"拾色"二字衬线宋体，配一个极简图形符号——
一滴墨晕染成色环的抽象形，或一方印章式的色块。要求：单色（墨）+ 朱砂两个版本，
SVG 矢量风格，极简，小尺寸（24px）下仍可辨识。同时给出 favicon 版本。
产出：logo-light.svg、logo-dark.svg、favicon。
```

### M2 · 首页 UI 稿

```
【基调】（见上）
设计「拾色 · 东方」首页（1440px 桌面 Web）：
- 顶栏：左 Logo，中间导航（色谱 / 收藏 / 关于），右深色模式开关 + 当前主题色小色点
- Hero：大幅留白，衬线大标题「中国色，不止于色」级别的一句话主张 + 一句副文案，
  下方一排四季/色系入口（春 / 夏 / 秋 / 冬 / 全色谱）
- 色谱墙：色卡网格（每卡 = 色块 + 色名 + 拼音小字），hover 微上浮；
  顶部有九色系筛选条（红橙黄绿青蓝紫褐 + 黑白灰）与搜索框
- 页脚：hairline 分隔，小字版权与「基于 OKLCH 色阶引擎」说明
产出：首页 UI 稿（亮色 + 深色两版）。
```

### M3 · 色卡详情抽屉 UI 稿

```
【基调】（见上）
设计色卡详情（右侧滑出抽屉，宽约 560px）：
- 顶部：大色块区（占抽屉高约 1/3），色名衬线大字 + 拼音 + 诗词一句（小字灰色）
- 色值区：HEX / RGB / OKLCH 三行等宽字体，点击复制
- 色阶区：10 级色阶横带（由浅到深），主色级有小标记
- 墨阶区：14 级中性灰横带（更矮）
- 搭配色：互补 / 类似 / 三角三组小色块
- 底部主按钮：「设为全站主题」（朱砂底）+ 次按钮「收藏」「分享」
产出：抽屉 UI 稿（亮色 + 深色两版）。
```

### M4 · 图标组

```
【基调】（见上）
设计一组线性图标（24px 网格、1.5px 描边、圆角末端）：
搜索、收藏（心/书签、含已收藏态）、分享、深色模式（月）、浅色模式（日）、
复制、关闭、筛选、下载、色滴（主题）。风格参考 Lucide，保持同一描边语言。
产出：icons.svg sprite 或独立 SVG ×10。
```

### M5 · 插画 / 空状态

```
【基调】（见上）
设计两幅扁平插画：
1. 收藏页空状态——一张留白宣纸上一方小印章，配文案位
2. 关于页头图——抽象的"墨色在水中晕染成色谱"长条横幅（横版，极克制，不超过 3 个色相）
产出：empty-favorites.svg、about-banner.svg（亮/深色背景各一版）。
```

### M6 · 分享卡片模板

```
【基调】（见上）
设计色卡分享图模板（1200×630，用于 Canvas 导出 PNG 的版式参照）：
左侧 40% 为纯色大色块，右侧米白底上色名（衬线大字）、诗词、HEX（等宽）、
底部一条 10 级色阶细带，右下角小 Logo。版式留白大方。
产出：share-card 模板图 + 标注尺寸/字号/间距的规范说明。
```

## 产出登记

每项产出完成后在《全流程记录.md》的「Miora 产出」节登记：文件名、用途、对应任务号、是否符合基调（如跑偏记录迭代次数与修正 prompt）。
