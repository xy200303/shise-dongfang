# 「拾色 · 东方」产品定义

> 犀鸟鸟 2026 实战 Task 02 · 中国传统色主题馆
> 版本 v0.1 · 2026-08-25

## 一、产品动机

中国传统色是一座被低估的宝库：胭脂、天青、月白、黛蓝……每个名字背后都有诗词与物候。
但现有传统色网站大多停留在「色值列表」层面——好看，却不可用。
设计师真正需要的是：**看到一只传统色，就能立刻知道它在真实界面里怎么用**——
它的 10 级色阶长什么样、配什么灰、和哪些色和谐、当主题色时组件效果如何、文字对比度是否达标。

「拾色 · 东方」把 Task 01 的色阶引擎装进传统色主题馆：
**每一只传统色都不是一个死色值，而是一套可即取即用的、经过感知均匀与可访问性校验的设计系统种子。**

## 二、产品定位

- 一句话：可穿在身上的中国传统色——浏览、理解、应用一条龙
- 目标用户：UI 设计师、前端工程师、对东方美学感兴趣的创作者
- 形态：Web 桌面端应用（TDesign React），单仓库 `apps/gallery`，复用 `@palette-studio/core`

## 三、核心功能（闭环）

1. **色谱浏览**：200+ 传统色的色彩墙，按九大色系 / 四季筛选，按名搜索
2. **色卡详情**：大色块 + 诗词出处 + hex/rgb/OKLCH；引擎实时生成 10 级色阶、14 级中性墨阶、搭配色（互补/类似/三角）
3. **一键上身（核心亮点）**：任意色「设为全站主题」→ 引擎生成整套 TDesign Design Token → 全站组件即时换装；支持深色模式（暗色色阶重新生成）
4. **收藏**：localStorage 持久化，收藏页可回顾
5. **分享**：生成色卡分享图（Canvas 导出 PNG：色块 + 色名 + 诗词 + 色阶条）
6. **关于页**：产品理念 + 引擎算法 + 可访问性说明（墨分五色 / 随类赋彩 / 双轨校验）

## 四、信息架构

```
首页（色谱墙 + 筛选 + 搜索）
 ├─ 色卡详情（抽屉式，不打断浏览）
 ├─ 收藏
 └─ 关于（理念 / 算法 / 可访问性）
顶栏：Logo · 导航 · 深色模式开关 · 当前主题色指示
```

## 五、设计理念（给 Miora 的基调输入）

- **美学关键词**：宋式极简、留白、宣纸、墨色、朱砂点睛；东方编辑排版
- **墨分五色**：界面的灰阶不是纯灰，是跟随主题色色相的「墨阶」（引擎中性色能力）
- **随类赋彩**：页面外壳保持宣纸/玄色中性，色彩全部让位给传统色本身
- **少即是多**：无渐变堆砌、无装饰性圆角、动效克制（150–250ms）
- 亮色模式：宣纸米白底（#faf8f4 级）、墨黑文字；深色模式：玄色底（近黑带暖意）、米白文字

## 六、与 Task 01 的关系

Task 01 交付的是引擎与工具站；Task 02 是引擎的产品化落地。
同一仓库 monorepo：`packages/core`（引擎）→ `apps/demo`（工具站）→ `apps/gallery`（主题馆）。
评审可在同一代码仓看到「算法 → 工具 → 产品」的完整链路。
